# SQL Server MCP Server

A Model Context Protocol (MCP) server that provides seamless integration with on-premises SQL Server databases. This server enables AI assistants to interact with your SQL Server databases through a standardized interface.

## Features

- **Execute SQL Queries**: Run SELECT, INSERT, UPDATE, and DELETE operations
- **Schema Discovery**: Get table lists and detailed schema information
- **Table Management**: Create new tables with custom schemas
- **Data Insertion**: Insert data into existing tables
- **Secure Connection**: Uses ODBC with trusted connections to SQL Server
